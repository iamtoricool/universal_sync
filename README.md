# universal_sync

Cross-platform synchronization for Dart & Flutter applications.

## Features

- **Cross-Platform:** Out-of-the-box support for Dart & Flutter applications across Web, Mobile, and Desktop platforms.
- **Easy Integration:** Simple and intuitive API to get synchronization up and running.
- **Robust Syncing:** Keep your application data synchronized and up-to-date across platforms.

## Getting started

Add `universal_sync` as a dependency in your `pubspec.yaml`:

```yaml
dependencies:
  universal_sync: ^0.0.1+1-alpha
```

Then run `dart pub get` (or `flutter pub get`) in your terminal.

## Usage

A simple usage example:

```dart
import 'package:universal_sync/universal_sync.dart';

void main() {
  var awesome = Awesome();
  print('awesome: ${awesome.isAwesome}');
}
```
